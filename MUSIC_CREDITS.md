The GitHub Actions workflow (.github/workflows/import-cc0-music.yml) can download the original tracks and generate the AAC files for the game bundle. If GitHub Actions is not enabled or its token is not allowed to push, run Scripts/import_cc0_music.py locally and commit the resulting two m4a files.
