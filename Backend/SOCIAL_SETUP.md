# REDACTED Social setup

The independent **REDACTED ID** service now uses emailed verification codes
instead of anonymous-only/device-bound sign-in. The current setup instructions
for Friends, Task Forces, account recovery, cloud saves, and 1v1 multiplayer
are in [REDACTED_ID_SETUP.md](REDACTED_ID_SETUP.md).

Use that guide before configuring a new Supabase project. The old anonymous
sign-in instructions are retired.
